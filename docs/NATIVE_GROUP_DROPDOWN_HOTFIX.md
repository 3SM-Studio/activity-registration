# Native group dropdown hotfix

This hotfix documents the production issue found during the schema v4 rollout on 2026-08-21.

Google Sheets rejects `setDataValidation` on a typed native Table column. `ASSIGNED_GROUP_ID` therefore uses a native Table `DROPDOWN` column with `ONE_OF_LIST`, populated from the active current-season group IDs generated by `PANEL_OPERATORA` during bootstrap.

The temporary workflow used to apply the code change is intentionally not part of the final pull request.
